# Galeria De HOMÈ website

React + Vite + Tailwind rebuild of galeriadehome.com.

## Run it
```
npm install
npm run dev
```

## Where to edit
- `src/data/site.js` — text, menu links, hero image, products
- `src/components/` — Hero, LiveClock, Menus, ProductGrid
- `src/index.css` — colors and fonts (Tailwind theme)

Product links go to the Shopify store for cart and checkout.
